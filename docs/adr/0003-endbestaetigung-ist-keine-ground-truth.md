# 0003 Endbestätigung ist keine Ground Truth

Status: gültig

Kontext: Ein bestätigtes Objekt wirkt leicht wie eine geprüfte Referenz. Dafür fehlt hier die unabhängige Zweitprüfung.

Entscheidung: Die Endbestätigung verlangt eine benannte Person, ausdrückliche Zustimmung, alle bestätigten Bereiche und keine Blocker. Sie bedeutet nur, dass der gespeicherte Arbeitsstand durchgesehen wurde. Offene fachliche Hinweise sperren sie; sie werden dafür weder abgewiesen noch ausgeblendet. Belegte Unterschiede können begründet entschieden werden und bleiben dabei sichtbar (siehe 0005). Jede inhaltliche Änderung hebt sie auf.

Folgen: Oberfläche und Protokoll sagen dies jedes Mal dazu. Eine Ground-Truth-Freigabe gibt es nicht.
