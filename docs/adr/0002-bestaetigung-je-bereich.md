# 0002 Bestätigung je Prüfbereich

Status: gültig

Kontext: Eine einzige Freigabe für ein Objekt würde verdecken, was tatsächlich am Bild geprüft wurde.

Entscheidung: Regionsgrenzen, Beschreibung, Suchbegriffe und jede Transkription werden einzeln mit Name und Zeitpunkt bestätigt. Nur eine inhaltliche Änderung setzt den betroffenen Bereich zurück, eine unveränderte Eingabe nicht. Frühere Bestätigungen bleiben im Prüfprotokoll.

Folgen: Eine Bestätigung gilt dem angezeigten Stand und wird abgelehnt, wenn der Inhalt inzwischen anders gespeichert wurde.
